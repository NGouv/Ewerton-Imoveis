Configuração pendente

Para habilitar o painel

  1. Crie um projeto Supabase e copie a Project URL e a chave anon/public.
  2. Preencha SUPABASE_URL e SUPABASE_ANON_KEY em js/supabase-config.js.
  3. Execute supabase/migrations/202611240001_admin_properties.sql no SQL Editor do Supabase.
  4. Crie o usuário em Authentication → Users no Dashboard do Supabase.
  5. Copie o UUID desse usuário e adicione-o à tabela public.admin_users pelo SQL Editor (instruções no arquivo da migration).
  6. Publique o site num servidor HTTPS; o login não funciona abrindo o HTML via file://.

Até concluir esses passos, não há login, dados ou operações simuladas. A área administrativa permanece bloqueada.
